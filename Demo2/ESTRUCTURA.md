# Estructura del banco

- `paa_20_reactivos_estructurado.json`: banco estructurado.
- `README.md`: versión Markdown para GitHub.
- `images/`: figuras extraídas del PDF y referenciadas desde ambos
  formatos.

Las rutas de imagen son relativas, por lo que al subir toda la carpeta a
GitHub las figuras se muestran desde `README.md`.
